When you’ve descended the seven levels, step into the real thing: a closed‑loop OpenPLC controller driving a simulated wet‑well, fronted by a DNP3 outstation and an MQTT telemetry path, across five segmented IEC‑62443 zones with an nftables conduit firewall — yet every packet still shows up in Wireshark. 5 zones→ OpenPLC logic→ DNP3 + MQTT on the wire→ inject the attack→ harden it out

Launch it from the Codespace terminal — the loopback lab pauses, the Learning Path stays on :8080:

$ bash lab/twin/launch-twin.sh --attack   # adversary foothold → run the injection, spill climbs
$ bash lab/twin/launch-twin.sh --hardened # same attack, refused — spill stays 0

Objective: keep the Sanitary‑Sewer‑Overflow spill counter at 0 under full DNP3 + MQTT write access. Doors once it boots: OpenPLC :8088 · HMI :1881 · Wireshark :3000.
